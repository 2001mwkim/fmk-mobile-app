# 애플워치 실기기 점검 체크리스트 (0.1.7+44)

CLAUDE.md 미해결 사항("실기기에서의 위젯·알림·컴플리케이션 동작 미점검")을
이번 빌드로 점검하기 위한 목록. 0.1.7 은 워치 실기기 전용 버그(arm64_32 32비트
잘림) 2건을 고쳤으므로 **반드시 실기기에서** 확인해야 한다 — 시뮬레이터는
64비트라 고친 버그 자체가 재현되지 않는다.

## 준비

- [ ] 아이폰에 0.1.7+44 설치 후 **앱을 한 번 열어** 브리지 저장 + 워치 동기화 실행
- [ ] 워치에 워치 앱이 설치됐는지 확인(Watch 앱 › 일반 › 앱 설치)
- [ ] 워치 설정 › 개인정보 보호에서 컴플리케이션 갱신 허용 상태 확인

## 1. 이번에 고친 버그 회귀 확인 (핵심)

- [ ] **D-day**: 일정 컴플리케이션·워치 앱에 다음 세션(이탈리아 GP, 9/4 FP1)이
      `D-N` 으로 나오는가? ← 0.1.6 은 항상 "D-DAY"/"오늘" 로 굳어 있었다
- [ ] 날짜가 바뀌면 D-day 숫자도 줄어드는가(다음날 재확인)
- [ ] **팀 컬러**: 라이브/결과 표시에서 드라이버 색이 팀별로 다른가?
      ← 0.1.6 은 전부 폴백 레드였다

## 2. 컴플리케이션 표시 (사진 시계 포함)

- [ ] 사진 시계 얼굴: 원형·코너 슬롯에 `FP1` / `D-9` 꼴로 **잘리지 않고** 나오는가
- [ ] 코너 슬롯의 곡선 라벨(`FP1 19:30`, `P1 428pt`)이 끝까지 보이는가
      ← 곡선 라벨 폭은 계산으로 검증 불가, 실기기로만 확인 가능
- [ ] 인라인(시계 위 한 줄): `🏁 FP1 9.4 금 19:30` 전체가 보이는가
- [ ] 사각형: 드라이버 순위 Top 3 / MY DRIVER 정보가 온전한가
- [ ] 3종(일정·라이브 / 드라이버 순위 / MY DRIVER) 모두 갤러리에 나타나는가

## 3. 데이터 동기화

- [ ] 아이폰 앱에서 MY DRIVER 변경 → 워치 컴플리케이션에 반영되는가
      (지연 확인: updateApplicationContext 는 즉시가 아닐 수 있음, 수 분 허용)
- [ ] 아이폰 앱을 며칠 안 열어도 세션 경계에서 다음 세션 표시가 넘어가는가
      (타임라인 엔트리 기반 — 앱 재실행 불필요해야 정상)

## 4. 세션 창 라이브 (9/4 금 19:25~ FP1 창에서)

- [ ] 세션 시작 5분 전부터 일정 컴플리케이션이 LIVE 표시로 전환되는가
- [ ] P1~P3 순위·랩타임(BEST)이 갱신되는가(8분 간격이므로 여유 있게)
- [ ] 세션 종료 40분 후 일정 표시로 복귀하는가
- [ ] (사고 대비) 라이브가 안 나오면: 아이폰 설정 › 라이브 연결(디버그 빌드)에서
      endpoint 가 폴백(railway)으로 넘어갔는지 확인

## 5. 아이폰 위젯·알림 (같은 김에)

- [ ] 잠금화면 원형 위젯 D-day 표기 정상
- [ ] 홈 일정 위젯·순위 위젯·MY PICKS 위젯 정상
- [ ] 세션 알림(알림 설정 켠 상태로 세션 창 진입 시) 도착
- [ ] Live Activity(Now Bar)가 레이스 중 표시되는가
